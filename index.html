Canvas Tasks Sync

A personal tool that copies dated assignments and events from a Canvas calendar feed into Google Tasks.

The tool runs on its owner's Linux computer. It uses course names and item titles to organize tasks into My Tasks, Midterms and Finals, and checks periodically for changes to titles and dates.

Google account access

The owner authorizes access to Google Tasks so the tool can read task lists and create, update and move its synced tasks. This website does not sign users in or receive their calendar data or credentials.

Personal use

This is a personal integration, not a public hosted synchronization service. It is not affiliated with or endorsed by Simon Fraser University, Instructure or Google.
