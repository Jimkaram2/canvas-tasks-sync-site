Canvas Tasks Sync

Privacy policy

Effective September 20, 2026.

Canvas Tasks Sync is a personal application operated by its account owner on their own computer.

Data accessed and used

The application reads a private Canvas calendar feed, including event identifiers, titles, course labels, dates and links. It accesses Google task lists and tasks, including titles, notes, due dates and completion status, to find its previously synced tasks and avoid duplicates.

It sends course-prefixed titles, dates, Canvas event links and source identifiers to the owner's Google Tasks account. It creates, updates and moves its synced tasks. Calendar feeds do not supply Canvas submission status; the owner manages completion in Google Tasks.

Storage and security

The private feed URL, Google OAuth client credentials and Google access/refresh tokens are stored as files on the owner's computer. The application uses HTTPS for remote requests and restricts credential file permissions. Service logs on that computer may contain task titles and sync results. Synced tasks remain stored by Google.

Sharing

The application communicates with Canvas and Google to perform synchronization. It does not sell data, use it for advertising, or send it to analytics or AI services. This public information website contains no application credentials, private feed URL or task records, and uses no application analytics or cookies. GitHub Pages, as the hosting provider, may process ordinary web request information under GitHub's privacy statement.

Control and deletion

The owner can stop the scheduled service, revoke Google account access, remove local credential files and logs, and delete synced tasks in Google Tasks. Revoking authorization or stopping the service does not automatically delete existing tasks. A compromised Canvas feed link should be reset using the options available through Canvas or institutional support.

Google API data

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Questions and changes

For questions, use the developer support email displayed on this application's Google authorization screen. This policy will be updated if the application's data handling changes.
